Back the beggining of 2026 when I was learning the basics of Go in a small project that creates a new file based on a template, I have come across a small little error in my program.

My program didn't detected the extension of input, so if you sent "note.md", the program would create a file named "note.md.md".

Question: is this a bug?

Although computer science and software engineering are a niche affair and hobbie, for the most part, one thing that almost every person who had a slight interaction with a computer or videogames may know, is a bug, or a glitch even.

But when a program does a error like, putting another duplicate extension after creating a file, is it a bug? Because generally a bug is said to be a error in a program, however this behavior is well defined in the logic of the programer. The engineer (I), has not thought to check if there exists already a extension in the input, so the logic does not check for it, but yet for the user of application (I as well), there is indeed a unitended behavior, which is normally called a bug. Interesting...
